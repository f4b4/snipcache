# VS Code shortcuts

| Action                  | Linux / Windows    | macOS             |
| ----------------------- | ------------------ | ----------------- |
| Command palette         | `Ctrl+Shift+P`     | `Cmd+Shift+P`     |
| Quick open file         | `Ctrl+P`           | `Cmd+P`           |
| Multi-cursor next match | `Ctrl+D`           | `Cmd+D`           |
| Toggle terminal         | ``Ctrl+` ``        | ``Ctrl+` ``       |
| Go to symbol            | `Ctrl+Shift+O`     | `Cmd+Shift+O`     |
